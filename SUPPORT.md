# Support

Better Network Tools v0.1.0 is a source preview. Support is community and
maintainer best effort; there is no response-time guarantee and no signed
installer or packaged desktop application yet.

## Get help

Before opening an issue:

1. Confirm the host meets the versions in [README.md](README.md).
2. Run `scripts/bootstrap.py` again and note the first error.
3. Check that the web UI is at `http://127.0.0.1:3000` and the API is on the
   configured loopback port.
4. Compare local settings with [`.env.example`](.env.example) and review the
   [security guide](docs/security.md).
5. Search existing [GitHub
   issues](https://github.com/erichbrinkman/betternetworktools/issues).

Use the repository's support-question or bug-report issue form for public,
non-sensitive help. Include the commit or version, operating system, Python and
Node.js versions, package manager, exact steps, expected result, and actual
result.

## Protect sensitive information

Before posting, remove credentials, tokens, private keys, device names, customer
or employer information, public and private addresses when sensitive, complete
network inventories, transfer paths, terminal history, packet contents, and
unredacted logs or screenshots.

Security vulnerabilities must use the private reporting process in
[SECURITY.md](SECURITY.md). Do not open a public support issue for them.

## Other channels

- Product suggestions may use the hosted private feedback form described in
  [PRIVACY.md](PRIVACY.md).
- Contribution proposals and development setup are covered in
  [CONTRIBUTING.md](CONTRIBUTING.md).
- Release and updater behavior is covered in [RELEASE.md](RELEASE.md).

The project cannot provide emergency network-operations support, incident
response, or guarantees for production environments.
